# Smart Queue System

A capstone project built with Laravel for managing queueing, service categories, and receipt printing.

## Overview

This application helps manage queue tickets and related service workflows.

## Project Docs

- [Deployment Testing Runbook](./DEPLOYMENT-TESTING.md)
- [Project Features (What, Why, How)](./PROJECT-FEATURES-WHAT-WHY-HOW.md)

## Local Print Service

A companion Windows USB ESC/POS print service is available in [`print-service/`](./print-service/README.md) for silently printing queue receipts from Laravel.

## Getting Started

1. Clone the repository
2. Install Laravel dependencies
3. Configure your environment
4. Run the application
